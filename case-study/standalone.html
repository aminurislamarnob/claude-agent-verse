A local 3D office for watching the coding agents on my machine

Between 7 and 11 October 2026 I designed and built Claude Agent Verse, a local, browser-based 3D office that shows the Claude Code and Google Antigravity sessions running on my machine. Every live session sits at a desk in its project's pod, subagents pull up a chair as interns, and each character holds up an amber ! paddle when an agent is waiting on me. I wrote all 19 commits on develop (10 pair-written with Claude Code) across 13 merged pull requests.

The brief 7 Oct

The brief: see every blocked agent on a second monitor

I often run 10 to 20 Claude Code sessions at once across different projects, and several spawn their own subagents. Finding out which session finished its turn and which one is blocked on a permission prompt meant cycling through terminal tabs. I wrote the v1 spec in issue #1 around five rules.

Observe-only
v1 never sends input to an agent, approves permissions, or stops processes. It only watches.
Body language over graphs
A character's pose shows its state from across the room: typing while working, hand on chin while thinking, an amber ! paddle held up when waiting on me, hands on head on error, and leaning back when idle.
Localhost and token lockdown
The server binds to 127.0.0.1, checks the Origin header on HTTP and WebSocket upgrades, and requires a 16-byte random startup token on the browser WebSocket and a 32-byte token on POST /api/hooks.
Credentials stay unopened
Adapters read only session registry JSON entries (~/.claude/sessions/*.json), Claude project transcripts, and Antigravity's brain/*/.system_generated/logs/transcript.jsonl. Per-session token files and OAuth files in ~/.gemini are never opened.
Defensive adapters
Neither Claude Code's transcripts nor Antigravity's JSONL steps are a public API. Adapters skip unknown event types and malformed fields without throwing.
Architecture 7 Oct

One pure reducer between disk tailers and Three.js

I split the pnpm monorepo into three packages on Node 24: core, server, and web. Every state rule lives in core inside a pure function reduce(office, domainEvent) → office that does no I/O. The server scans process registries, tails JSONL transcripts, receives hook events, feeds them into reduce, and broadcasts the resulting Office over WebSocket.

Keeping core pure gave me a single test seam. All 44 reducer tests feed synthetic registry and transcript events through reduce and assert on the returned Office, while the 3D scene is checked visually through replay mode (pnpm --filter @claude-agent-verse/server replay) and preview mode (?preview=still).

Studio & breaks 8 Oct

Chibi developers, break zones, and real registry paths

On 8 October I replaced the first-pass diorama with a single open-plan software studio in PR #24 (615adc3). Each session gets a deterministic chibi developer from its session ID (skin tone, hair, hoodie, glasses, headphones), while about one developer in five wears a white taqiyah prayer cap, thobe, and Sunnah beard (5f7a66a). Interns wear team-coloured beanies. I also replaced drei Html labels with a fixed overlay portal after finding that labels mounted before the canvas connected rendered empty, and removed ~4 MB of unused GLB files.

In PR #25 (2d6d5b7) and PR #26 (259fe77) I added a 5-minute break threshold (breakThresholdMs). When a session stays idle for five minutes, its character stands up, walks down the pod aisle to the ping-pong table, coffee bar, sofa, or reshaped bean bags (12 spots total), and runs back to its desk as soon as new transcript activity arrives.

Watching my own live sessions exposed two bugs that I fixed in PR #27 (ff05778). First, a session whose last transcript line was a tool call stayed stuck in working or waiting_on_user after its turn ended; I added a session_status event carrying the registry's own busy/idle flag so idle wins unless a permission hook is open. Second, project paths containing a dot (such as .claude or acme.app) missed their transcripts because Claude Code turns every non-alphanumeric character into - in the project slug.

Speed 8 Oct

Speed: cutting draw calls by 47% and shadow draws by 82%

With 19 live sessions open at 3200×2000, the scene issued 4,596 draw calls per frame and re-rendered the shadow map on every frame because the server broadcast a fresh copy of Office on every one-second tick even when nothing changed.

In commit e609945 I made two changes. On the server, dispatch compares the reducer's return reference (if (office !== before)) and coalesces broadcasts to at most one snapshot per 100 ms. In packages/web, I built StaticBatch, which merges all static meshes under a desk or room into one BufferGeometry per material key while letting animated parts (userData.live: screens, mug steam, arcade display, ping-pong ball) stay separate. CPU time per frame fell from 12.6 ms to 8.4 ms.

Antigravity 11 Oct

A second room for Google Antigravity agents

On 11 October I merged PR #29 (249e1c4) to watch Google Antigravity conversations alongside Claude Code. Each agent kind gets its own room, switched from tabs in the top bar that show per-room agent and waiting counts while the browser tab title totals every room.

Passive brain tailing
Antigravity has no process registry, so packages/server/src/antigravity.ts lists ~/.gemini/{antigravity,antigravity-ide,antigravity-cli}/brain/* and treats a conversation as live while its transcript.jsonl was modified in the last 30 minutes, assigning a synthetic negative PID.
Stat-only workspace resolution
Once a tool call in transcript.jsonl names a path outside ~/.gemini, workspaceDir checks the path on disk with stat (so a Makefile or .env resolves to its parent folder and a directory named acme.app is kept) and moves the agent into its project pod.
Shared state reducer
processAntigravityStep maps USER_INPUT, PLANNER_RESPONSE, GENERIC, and ERROR_MESSAGE into the same AgentState values, so passive 15 s waiting inference and 5-minute breaks work without special cases.
Under the hood

The details a visitor never sees

Loopback, Origin, and two tokens
HTTP and WebSocket requests from foreign Origin headers get 403 Forbidden. Browser WebSockets must pass ?token=<browserToken> (16 random bytes per start); hook forwarders authenticate with Bearer <hookToken> (32 random bytes stored in ~/.claude/agent-verse-discovery.json with mode 0600 and unlinked on exit).
Coexisting hook installer
updateHooks tags only its own forwarder entry (# claude-agent-verse) across the 10 Claude hook events (SessionStart through SubagentStop), leaving hooks from Orca, Agent Flow, or Superset untouched and backing up .claude.json to .claude.json.bak before writing.
5-file Vitest suite (72 tests)
44 reducer tests in packages/core/src/reducer.test.ts, 11 Antigravity scanner/workspace tests, 9 Origin and token auth tests, 6 hook installer tests, and 2 registry scanner tests run in ~160 ms.
